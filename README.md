# HotelCalivornia

A college test project developed in Java to demonstrate the principles of object-oriented programming (OOP) through a hotel management application.

## Learning Objectives

This project demonstrates the use of:

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Interfaces
- Constructors and method overloading
- Collections and object relationships
- Basic application structure in Java

## Domain

The application models common hotel-related entities and processes, such as:

- Hotels and rooms
- Guests and reservations
- Room availability
- Check-in and check-out operations
- Hotel services and management logic

The exact functionality may evolve as the project is developed for coursework.

## Technologies

- **Language:** Java
- **Project type:** College OOP test project
- **Main topic:** Object-oriented programming

## Getting Started

### Prerequisites

- Java Development Kit (JDK) 8 or newer
- An IDE such as IntelliJ IDEA, Eclipse, or Visual Studio Code with Java support

### Running the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/Shevanka/HotelCalivornia.git
   ```

2. Open the project in your preferred Java IDE.
3. Configure the project to use an installed JDK.
4. Locate the main application class.
5. Run the application.

If the project uses a build tool in the future, the corresponding build and run instructions can be added here.
